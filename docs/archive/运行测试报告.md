### 2.4 安装测试 (install)

#### 问题发现
**第一次安装失败**:
```
错误: HRESULT: 0x800B0109, 已处理证书链，但是在不受信任提供程序信任的根证书处终止。
```

**原因**: 证书未安装到受信任的根证书颁发机构

#### 手动修复
```powershell
Import-PfxCertificate -FilePath "TestCompany.pfx" `
  -CertStoreLocation Cert:\LocalMachine\Root `
  -Password (ConvertTo-SecureString -String "test1234" -Force -AsPlainText)
```

#### 测试命令
```powershell
.\publish\msixtool.exe install --src D:\TestMsixApp_1.0.0.0.msix
```

#### 测试结果
✅ **通过** (手动安装证书后)
- 找到 MSIX 文件
- PowerShell Add-AppxPackage 执行成功
- 应用安装到 `C:\Program Files\WindowsApps\`

**建议改进**: 工具应自动安装证书到受信任根
