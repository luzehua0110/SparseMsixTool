# Legacy Release Archive

This directory contains historical release artifacts from the **MsixTool** era (v2.x internal development versions).

## Archive Status

These releases are **no longer maintained** and are preserved for historical reference only.

- **MsixTool-v2.x.x-*.zip**: Internal development versions (pre-rebranding)
- **MsixTool-*.zip**: Timestamped development builds

## Current Release

The current official release is **SparseMsixTool v1.0.0** and later versions.

Please download the latest version from:
- [GitHub Releases](https://github.com/luzehua0110/SparseMsixTool/releases)
- Main releases directory: `../`

## Migration Note

If you are using an archived MsixTool v2.x version:
1. Uninstall existing packages created with old tool
2. Download SparseMsixTool v1.0.0+
3. Use `sparsemsix` command instead of `msixtool`
4. Refer to [documentation](../../README.md) for updated commands
