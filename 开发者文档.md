## 构建和发布

### 快速构建

#### 使用自动化脚本（推荐）

项目提供了 `tools/package.ps1` 脚本，用于自动化发布和打包：

```powershell
# 标准 AOT 编译（默认已开启）
powershell -ExecutionPolicy Bypass -File tools/package.ps1

# AOT 编译 + 生成 latest 别名
powershell -ExecutionPolicy Bypass -File tools/package.ps1 -LatestAlias

# 指定运行时架构
powershell -File tools/package.ps1 -Runtime win-x86

# 不添加时间戳（生成固定文件名）
powershell -File tools/package.ps1 -NoTimestamp
```

#### 脚本参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `-Runtime` | string | `win-x64` | 目标运行时架构（win-x64, win-x86, win-arm64） |
| `-Aot` | switch | **是**（已默认开启） | 启用 Native AOT 编译（生成原生代码，无需 .NET 运行时）。项目默认开启 AOT，此参数保留用于显式声明 |
| `-NoTimestamp` | switch | 否 | 不在文件名中添加时间戳 |
| `-LatestAlias` | switch | 否 | 生成 `SparseMsixTool-latest.zip` 别名副本 |

#### 输出文件

- **标准输出**：`SparseMsixTool-v{Version}-{yyyyMMdd}.zip`（如 `SparseMsixTool-v1.0.0-20251031.zip`）
- **无时间戳**：`SparseMsixTool-v{Version}.zip`（使用 `-NoTimestamp` 时）
- **别名文件**：`SparseMsixTool-latest.zip`（使用 `-LatestAlias` 时）

#### 工作流程

1. **清理发布目录**：删除旧的 `publish` 文件夹
2. **执行 dotnet publish**：
   - 配置：Release
   - 运行时：指定架构（默认 win-x64）
   - 自包含：true
   - AOT：根据 `-Aot` 参数决定是否启用
3. **验证输出**：确认 `sparsemsix.exe` 生成成功（保留兼容别名 `msixtool.exe`）
4. **打包压缩**：将发布内容打包为 ZIP
5. **生成别名**：可选生成 latest 版本

### 手动发布

#### dotnet publish 命令说明

本项目使用 `dotnet publish` 命令进行构建和发布，支持多种编译模式：

**基础命令格式**：
```powershell
dotnet publish [选项]
```

**常用参数**：

| 参数 | 简写 | 说明 | 示例值 |
|------|------|------|--------|
| `--configuration` | `-c` | 构建配置 | `Release` / `Debug` |
| `--runtime` | `-r` | 目标运行时架构 | `win-x64` / `win-x86` / `win-arm64` |
| `--self-contained` | | 自包含部署（包含运行时） | `true` / `false` |
| `--output` | `-o` | 输出目录 | `publish` / `bin/Release` |
| `/p:PublishAot` | | 启用 Native AOT 编译 | `true` / `false` |
| `/p:PublishSingleFile` | | 发布为单文件 | `true` |
| `/p:PublishTrimmed` | | 裁剪未使用的程序集 | `true` |

#### Native AOT 编译（默认）

Native AOT 已在项目配置中默认开启（`MsixTool.csproj` 中 `<PublishAot>true</PublishAot>`），将 .NET 应用编译为原生代码，具有以下优势：
- **无需运行时**：生成的可执行文件不依赖 .NET 运行时
- **快速启动**：直接执行原生代码，启动速度更快
- **体积优化**：仅包含使用的代码，文件体积更小（~14.8MB）

```powershell
# 发布为 Native AOT（win-x64，默认已开启）
dotnet publish -c Release -r win-x64 --self-contained true -o publish

# 显式指定 AOT 编译（项目已默认开启，此命令效果相同）
dotnet publish -c Release -r win-x64 /p:PublishAot=true -o publish

# 其他架构
dotnet publish -c Release -r win-x86 --self-contained true -o publish    # 32位
dotnet publish -c Release -r win-arm64 --self-contained true -o publish  # ARM64
```

**注意**：由于项目配置中 `PublishAot=true`，所有 publish 命令默认使用 AOT 编译。

#### JIT 编译（可选）

如果需要禁用 AOT 使用标准 JIT 编译，需要在 `MsixTool.csproj` 中临时设置 `<PublishAot>false</PublishAot>`：

```powershell
# 自包含发布（包含 .NET 运行时）
dotnet publish -c Release -r win-x64 --self-contained true -o publish

# 框架依赖发布（需要用户安装 .NET 8.0 运行时）
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

**注意**：项目默认开启 AOT，如需 JIT 编译请先修改项目配置。

### 项目配置

#### Native AOT 配置（MsixTool.csproj）

Native AOT 已默认开启，项目配置如下：

```xml
<PropertyGroup>
  <TargetFramework>net8.0</TargetFramework>
  <RuntimeIdentifier>win-x64</RuntimeIdentifier>
  <PublishAot>true</PublishAot> <!-- 默认开启 AOT 编译 -->
  <InvariantGlobalization>false</InvariantGlobalization>
  <TrimMode>full</TrimMode>
  <IlcOptimizationPreference>Speed</IlcOptimizationPreference>
</PropertyGroup>
```

#### AOT 优化说明

- **PublishAot=true**：默认开启 Native AOT 编译
- **TrimMode=full**：启用完全裁剪，移除未使用的代码
- **IlcOptimizationPreference=Speed**：优化编译速度而非文件大小
- **InvariantGlobalization=false**：保留区域设置支持

#### PowerShell 调用规范（2025-11-03 新增）

为避免多行脚本、中文或 Unicode 符号导致 `-Command` 解析失败，所有复杂 PowerShell 脚本必须使用 Base64 `-EncodedCommand`：

```csharp
var script = $@"
$thumbprint = '{thumbprint}'
Write-Host \"[OK] Deleting {thumbprint}\"
";
var bytes = Encoding.Unicode.GetBytes(script);
var encoded = Convert.ToBase64String(bytes);
var (ok, stdout, stderr) = await WindowsSdkHelper.ExecuteCommandAsync(
    "powershell.exe",
    $"-NoProfile -EncodedCommand {encoded}");
```

规范要求：
- 输出统一使用英文，减少编码差异
- 脚本内避免出现未配对的引号；处理用户输入时 `Replace("'", "''")`
- 捕获失败后记录原始 `stderr` 内容
- 不直接使用 `-Command` 传递多行含中文脚本

常见禁止示例：
```csharp
// ❌ 禁止：直接 -Command 传递多行脚本（含中文）
await WindowsSdkHelper.ExecuteCommandAsync("powershell.exe", $"-Command \"{script}\"");
```

### 命令参数校验逻辑

#### cert + password 联合校验

在 `sign`、`packandinstall`、`packandsign` 命令中实现：

```csharp
// 校验：提供 --cert 时必须同时提供 --password
if (!string.IsNullOrWhiteSpace(cert) && string.IsNullOrWhiteSpace(password))
{
    PrintError("提供 --cert 参数时必须同时提供 --password 参数");
    Console.WriteLine("用法: msixtool sign --src <包路径> --cert <证书路径> --password <密码>");
    Environment.Exit(1);
    return;
}
```

**设计原因**：
- 避免用户提供证书但忘记密码，导致签名失败
- 提供明确的错误提示，改善用户体验

### 使用示例：完整工作流

#### 示例 1：packandinstall 命令实现

```csharp
// 1. 参数校验
if (!string.IsNullOrWhiteSpace(cert) && string.IsNullOrWhiteSpace(password))
{
    PrintError("提供 --cert 参数时必须同时提供 --password 参数");
    Environment.Exit(1);
    return;
}

// 2. 回退逻辑（使用历史路径）
var finalDest = dest;
if (string.IsNullOrWhiteSpace(finalDest))
{
    finalDest = ConfigManager.GetLastExternalAppPath();
    if (!string.IsNullOrWhiteSpace(finalDest))
    {
        Console.WriteLine($"使用历史外部程序路径: {finalDest}");
    }
}
if (string.IsNullOrWhiteSpace(finalDest))
{
    PrintError("未提供 --dest 且无历史路径可以回退，必须指定外部程序路径。");
    Environment.Exit(1);
    return;
}

// 3. 打包
var packService = new PackageService();
var msixPath = await packService.PackSparsePackageAsync(sourcePath, packageName);

// 4. 处理证书
string? actualCert = cert;
if (string.IsNullOrEmpty(actualCert))
{
    var publisher = ManifestHelper.GetPublisherFromManifest(manifestPath);
    var certService = new CertificateService();
    actualCert = await certService.GetOrCreateCertificateAsync(publisher, sourcePath);
}

// 5. 签名
await packService.SignPackageAsync(msixPath, actualCert, password);

// 6. 安装
var installService = new InstallService();
await installService.InstallSparsePackageAsync(msixPath, finalDest, autoUninstall: !noAuto);

// 7. 保存路径供下次回退
ConfigManager.SaveLastExternalAppPath(finalDest);
```
