## 代码结构

### 架构设计

MsixTool 采用**分层架构**：

```
┌─────────────────────────────────┐
│     CLI Layer (Program.cs)      │  命令行接口层
├─────────────────────────────────┤
│  Command Layer (CommandBuilder) │  命令构建层
├─────────────────────────────────┤
│   Service Layer (Services/)     │  业务逻辑层
│   - PackageService              │
│   - InstallService              │
│   - CertificateService          │
├─────────────────────────────────┤
│   Utility Layer (Utils/)        │  工具层
│   - WindowsSdkHelper            │
│   - ManifestHelper              │
│   - CertificateValidator        │
├─────────────────────────────────┤
│   Config Layer (ConfigManager)  │  配置层
└─────────────────────────────────┘
```

### 核心类说明

#### 1. Program.cs

入口点，负责：
- 创建 RootCommand
- 注册子命令
- 执行命令

```csharp
public class Program
{
    public static async Task<int> Main(string[] args)
    {
        var rootCommand = CommandBuilder.BuildRootCommand();
        return await rootCommand.InvokeAsync(args);
    }
}
```

#### 2. CommandBuilder.cs

命令构建器，负责：
- 定义所有命令和选项
- 绑定命令处理器

**设计模式**: Builder Pattern

```csharp
public static class CommandBuilder
{
    public static RootCommand BuildRootCommand() { }
    private static Command CreatePackCommand() { }
    private static Command CreateInstallCommand() { }
    // ...
}
```

#### 3. PackageService.cs

打包服务，负责：
- MSIX 打包
- 数字签名
- 文件重命名

**核心方法**:
```csharp
public async Task<string> PackSparsePackageAsync(
    string sourcePath, 
    string? packageName, 
    string? certPath)
```

#### 4. InstallService.cs

安装服务，负责：
- 应用安装
- 应用卸载
- 应用查找

**核心方法**:
```csharp
public async Task InstallPackageAsync(
    string? sourcePath, 
    string? packageName, 
    string? destPath)
```

#### 5. CertificateService.cs

证书服务，负责：
- 证书创建（Windows SDK / PowerShell）
- 证书配置保存

**设计模式**: Strategy Pattern（双策略）

```csharp
public async Task CreateCertificateAsync(
    string publisherName, 
    string password = "1234567")
{
    // 策略1: Windows SDK (makecert + pvk2pfx)
    // 策略2: PowerShell (New-SelfSignedCertificate)
}
```

#### 6. ConfigManager.cs

配置管理器，负责：
- 配置文件读写
- 证书配置管理
- 无效路径清理

**设计模式**: Singleton Pattern

```csharp
public class ConfigManager
{
    private static ConfigManager? _instance;
    public static ConfigManager Instance { get; }
}
```

## 发布流程

### 版本号规范

遵循 **语义化版本** (Semantic Versioning):

```
格式: 主版本.次版本.修订号

示例:
1.0.0 → 1.0.1  # 修复bug
1.0.1 → 1.1.0  # 添加新功能（向后兼容）
1.1.0 → 2.0.0  # 破坏性更改
```

### 发布步骤

#### 1. 更新版本号

**MsixTool.csproj**:
```xml
<PropertyGroup>
  <Version>1.2.0</Version>
  <AssemblyVersion>1.2.0.0</AssemblyVersion>
  <FileVersion>1.2.0.0</FileVersion>
</PropertyGroup>
```

#### 2. 更新 CHANGELOG

**更新日志.md**:
```markdown
## [1.2.0] - 2025-10-24

### 新增
- 添加了 xxx 功能

### 修复
- 修复了 xxx 问题

### 优化
- 优化了 xxx 性能
```

#### 3. 编译发布版本

```powershell
# 清理旧的构建
dotnet clean

# 发布 Release 版本
dotnet publish -c Release -o .\publish

# 验证
.\publish\msixtool.exe --version
```

#### 4. 创建发布包

```powershell
# 创建发布目录
$version = "1.2.0"
$releaseDir = "Release-v$version"
New-Item -ItemType Directory -Path $releaseDir

# 复制文件
Copy-Item "publish\*" -Destination $releaseDir -Recurse
Copy-Item "config\app.config.json.template" -Destination "$releaseDir\config\"
Copy-Item "examples\*" -Destination "$releaseDir\examples\" -Recurse
Copy-Item "*.md" -Destination $releaseDir

# 创建压缩包
Compress-Archive -Path $releaseDir -DestinationPath "MsixTool-v$version.zip"
```

#### 5. 创建 Git 标签

```bash
git tag -a v1.2.0 -m "Release version 1.2.0"
git push origin v1.2.0
```

#### 6. GitHub Release

1. 访问 GitHub Releases 页面
2. 点击 "Draft a new release"
3. 选择标签: `v1.2.0`
4. 发布标题: `MsixTool v1.2.0`
5. 描述: 从 CHANGELOG 复制
6. 上传附件: `MsixTool-v1.2.0.zip`
7. 发布

## API 文档

### PackageService

#### PackSparsePackageAsync

```csharp
/// <summary>
/// 打包稀疏包并签名
/// </summary>
/// <param name="sourcePath">源目录路径，必须包含 AppxManifest.xml</param>
/// <param name="packageName">包名称，如果不指定则从清单文件读取</param>
/// <param name="certPath">证书文件路径（.pfx），如果不指定则从配置中查找</param>
/// <returns>生成的 MSIX 文件完整路径</returns>
/// <exception cref="FileNotFoundException">清单文件或证书文件不存在</exception>
/// <exception cref="InvalidOperationException">打包或签名失败</exception>
public async Task<string> PackSparsePackageAsync(
    string sourcePath, 
    string? packageName, 
    string? certPath)
```

**使用示例**:
```csharp
var service = new PackageService();
string msixPath = await service.PackSparsePackageAsync(
    sourcePath: @"D:\MyApp",
    packageName: null,  // 自动从清单读取
    certPath: null      // 自动从配置读取
);
Console.WriteLine($"包已创建: {msixPath}");
```

### 添加测试

```csharp
// MsixTool.Tests/PackageServiceTests.cs
public class PackageServiceTests
{
    [Fact]
    public async Task PackSparsePackageAsync_ValidInput_ReturnsPackagePath()
    {
        // Arrange
        var service = new PackageService();
        var sourcePath = @"D:\TestApp";
        
        // Act
        var result = await service.PackSparsePackageAsync(sourcePath, null, null);
        
        // Assert
        result.Should().EndWith(".msix");
        File.Exists(result).Should().BeTrue();
    }
    
    [Fact]
    public async Task PackSparsePackageAsync_InvalidPath_ThrowsException()

        // Arrange
        var service = new PackageService();
        
        // Act & Assert

        );
    }
}
```
